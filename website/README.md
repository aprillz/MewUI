# MewUI documentation site

Astro + Starlight site published to GitHub Pages at the `/MewUI/` sub-path of https://www.aprillz.net. Node is used only inside this folder; the .NET build never touches it.

## Build

```
cd website
npm ci
npm run build        # runs `npm run sync` first (prebuild), output in dist/
npm run check-links  # scans dist/ for internal links with no matching file
npm run dev          # local preview with live reload
```

`npm run build` works without the Gallery and without the API reference; `check-links` skips links into `api/` and `Gallery/` when those trees are absent in `dist/`.

## Where the content comes from

Nothing is authored under `src/content/docs/` except the two landing pages (`index.mdx`, `ko/index.mdx`). `scripts/sync-content.mjs` copies the repository Markdown in on every build:

| Source | Destination | Notes |
|---|---|---|
| `docs/<Name>.md` | `src/content/docs/<name>.md` | English topic guides (root locale) |
| `docs/<Name>.ko.md` | `src/content/docs/ko/<name>.md` | Korean translations |
| `docs/markup/<Name>.md` | `src/content/docs/markup/<name>.md` | Generated C# markup reference (`MewUI.MarkupAudit --docs`) |
| `docs/assets/**` | `public/assets/**` | Served at `/MewUI/assets/...` |
| `.artifacts/api/**` | `src/content/docs/api/**` | API reference produced by `tools/docs/build_api_docs.cmd`; the sync script leaves this tree alone |

The sync script takes the first `# ` heading as the page `title`, the first short paragraph as `description`, sets an explicit lowercase `slug`, and rewrites relative links: `Other.md` becomes `/MewUI/other/`, `Other.ko.md` becomes `/MewUI/ko/other/`, `markup/X.md` becomes `/MewUI/markup/x/`, `assets/...` becomes `/MewUI/assets/...`, and any path outside `docs/` becomes a link into the GitHub repository. Anchors are kept. The script deletes previously synced files first, so it is safe to rerun. The docs stay in `docs/`; edit them there, never under `src/content/docs/`.

## Locales

Starlight's root-locale convention realizes the en/ko split from `agent/documentation/plan.md` section 4.1: English is the `root` locale (`/MewUI/installation/`) and Korean lives under `ko/` (`/MewUI/ko/installation/`). Keeping English at the content root means the locale-neutral trees `api/` and `markup/` are naturally English-only and are linked with absolute paths from both locales. A topic without a Korean file falls back to the English page.

## Sidebar and the API reference

The sidebar in `astro.config.mjs` follows the information architecture of `agent/documentation/plan.md` section 3: Get started, Guides, Architecture, Reference. Topic pages are listed by slug; the `markup/` directory is autogenerated; the API reference is a single link to `/MewUI/api/`.

The `api/` directory is deliberately not autogenerated into the sidebar. It holds on the order of 5,000 pages, and Starlight renders the complete sidebar into every HTML page, so an autogenerated API group would multiply the size of every page on the site. Navigation inside the API reference comes from the generated index pages and the search index instead.

## API reference

`src/content/docs/api/` is produced by `tools/docs/build_api_docs.cmd` (xmldocmd plus `MewUI.MarkupAudit --api-crosslink`), not by this folder. The Pages workflow builds it on Windows, copies it into `website/src/content/docs/api/`, runs `npm ci && npm run build`, and stages `website/dist` at the site root next to `Gallery/`.

## Dots in slugs

Astro's default id generation strips dots from file names (`WebView2.Win32.md` would become `webview2win32`). The sync script and the API generator set `slug` in the frontmatter explicitly so that dotted names keep their dots in the URL (`/MewUI/markup/webview2.win32/`).

## Known behaviour

- Starlight generates a Korean fallback page for every English page that has no `ko/` counterpart, including every `markup/` and `api/` page (`/MewUI/ko/api/...` shows the English content with a "not translated" notice). With the API reference in place this doubles the page count and the Pagefind index.
- Sidebar link items are localized by Starlight, so the "API reference" item points to `/MewUI/api/` on English pages and to `/MewUI/ko/api/` (the fallback copy) on Korean pages. Links inside page bodies are absolute and always target the English `api/` pages.
- A page whose slug ends in `/index` is treated as the directory index, so an API member named `Index` (`<Type>/Index.md`) collides with the type page `<Type>.md`. The API generator must give such members a different slug.
- `astro build` prints two harmless warnings: the optional `i18n` collection is not defined, and the `404` entry lookup for Starlight's 404 page.
