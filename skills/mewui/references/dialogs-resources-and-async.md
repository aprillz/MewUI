# Use prompts, windows, files, images, and asynchronous work

## Message boxes

Prefer the managed async APIs and pass the owner window so modality, focus, and stacking are correct.

```csharp
var result = new ObservableValue<string>("No choice yet");

var confirmButton = new Button()
    .Content("Delete item")
    .OnClick(async () =>
    {
        bool accepted = await MessageBox.ConfirmAsync(
            "Delete the selected item?",
            icon: PromptIconKind.Warning,
            detail: "This action cannot be undone.",
            owner: window);

        result.Value = accepted ? "Deleted" : "Canceled";
    });
```

Use `NotifyAsync` for acknowledgement, `AskYesNoAsync` or `AskYesNoCancelAsync` for standard choices, and `PromptAsync(MessageBoxOptions)` for custom buttons. `NativeMessageBox.Show` is available when a platform-native blocking prompt is specifically required.

## Application-owned modal windows

Create a `Window`, set `StartupLocation` and `WindowSize`, then pass its owner to `ShowDialogAsync`:

```csharp
var editButton = new Button()
    .Content("Edit details")
    .OnClick(async () =>
    {
        var dialog = new Window
        {
            Title = "Edit details",
            StartupLocation = WindowStartupLocation.CenterOwner,
            WindowSize = WindowSize.FitContentSize(380, 240),
            Padding = new Thickness(16),
            Content = new TextBlock().Text("Dialog content"),
        };

        await dialog.ShowDialogAsync(window);
    });
```

Use `ShowDialog` only when a synchronous nested modal loop is intentional. Handle `Closing` and set `ClosingEventArgs.Cancel` when the user must confirm unsaved work. Buttons inside the dialog finish the operation by calling `Close()`.

## File dialog

File dialogs can prefer the native platform dialog and fall back to a managed dialog.

```csharp
var selectedPath = new ObservableValue<string>("No file selected");

var openButton = new Button()
    .Content("Open file")
    .OnClick(() =>
    {
        string? path = FileDialog.OpenFile(new OpenFileDialogOptions
        {
            Owner = window,
            Title = "Open file",
            PreferNative = true,
        });

        selectedPath.Value = path ?? "Canceled";
    });

var selectedPathText = new TextBlock().BindText(selectedPath);
```

Cancellation returns `null`; do not treat it as an error or pass it to file APIs. Use `OpenFiles`, `SaveFile`, or `SelectFolder` for other operations. Async variants accept a cancellation token. Always supply the owner window when it is available.

## Images

```csharp
var image = new Image
{
    Source = ImageSource.FromFile(imagePath),
};
```

For embedded resources, use `ImageSource.FromResource(assembly, resourceName)` or `ImageSource.FromResource<T>(resourceName)`. Ensure the file has the appropriate embedded-resource build action. Dispose or replace large image sources according to the ownership contract exposed by the selected package version.

Declare an embedded asset explicitly:

```xml
<ItemGroup>
  <EmbeddedResource Include="Assets\logo.png" />
</ItemGroup>
```

Then load its manifest name through an anchor type in the same assembly:

```csharp
var logo = new Image
{
    Source = ImageSource.FromResource<AppResources>("MewUIApp.Assets.logo.png"),
};

internal sealed class AppResources
{
}
```

The manifest name normally combines the project's root namespace and relative path. If it is unclear, inspect `typeof(AppResources).Assembly.GetManifestResourceNames()` during diagnosis rather than guessing. For downloaded or generated bytes, use `ImageSource.FromBytes(bytes)`.

SVG and Skia are optional packages, not built-in replacements for `Image`:

```text
dotnet add package Aprillz.MewUI.Svg
dotnet add package Aprillz.MewUI.Skia
```

Keep extension versions aligned with the core MewUI package set.

## Async event work

Use a named `async void` handler only at the UI event boundary. Catch failures there and update observable state after the awaited operation resumes.

```csharp
var status = new ObservableValue<string>("Ready");

async void Load()
{
    try
    {
        status.Value = "Loading";
        await Task.Delay(100);
        status.Value = "Loaded";
    }
    catch (Exception exception)
    {
        status.Value = exception.Message;
    }
}

var loadButton = new Button().Content("Load").OnClick(Load);
```

Do not block the UI thread with `.Wait()` or `.Result`.

## Temporary overlays

Add application-owned transient visuals to the window overlay layer and remove the same instance when finished:

```csharp
var overlay = new Border()
    .Padding(16)
    .Child(new TextBlock().Text("Working..."));

window.OverlayLayer.Add(overlay);
try
{
    await Task.Delay(100);
}
finally
{
    window.OverlayLayer.Remove(overlay);
}
```

Use a modal window or message box when owner input must be disabled. An overlay is appropriate for in-window decoration, progress, selection adorners, and non-modal transient UI.
